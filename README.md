# Wallpaper Studio

Local macOS live wallpaper player with a menu-bar selector. It scans:

`/Users/user/Documents/Wallpapers`

Choose a video from the 🎞️ menu-bar icon. The player creates one live wallpaper window per display and loops the selected MP4 locally.

## Build and run

```sh
./build.sh
```

The app is installed at `/Users/user/Applications/Wallpaper Studio.app`.
